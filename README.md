# MP3 批量处理工具

一个小工具，三个功能，可单独用，也可组合用：

1. **批量降低音量**：输入 mp3 文件或文件夹，按给定数值（分贝或百分比）统一调小；
2. **按标签重命名**：读取 ID3 信息，把**输出文件**命名为「歌曲名 - 歌手」；
3. **外文歌名翻译**：歌名/歌手出现中、英以外的文字（日文、韩文、俄文等）时，
   调用百度翻译 API 转成中文或英文后再命名。

**原文件始终不会被修改**：改音量、重命名都只作用于输出文件夹里的副本。

## 快速开始

双击 `启动工具.bat`（或运行 `python volume_tool.py`）打开界面：

1. 点右上角「设置…」；
2. 勾选「启用翻译」，填入百度翻译的 **APP ID** 和**密钥**；
3. 点「测试翻译」确认能用，然后「保存」；
4. 选择文件/文件夹 → 勾选「按 ID3 标签重命名」→ 开始。

命令行：

```
python volume_tool.py "D:\Music" -v 6
python volume_tool.py "D:\Music" --rename
python volume_tool.py "D:\Music" --rename --translate
```

## 设置页

设置保存在脚本旁的 `settings.json`（目录不可写时放到 `%APPDATA%\MP3BatchTools\`），
也可用命令行 `--settings 其它路径.json` 指定。

| 分组 | 选项 | 说明 |
| --- | --- | --- |
| 翻译 | 启用翻译 | 总开关；关闭时不联网、不调用 API |
| | APP ID / 密钥 | 百度翻译开放平台凭据 |
| | 接口地址 | 默认 `https://fanyi-api.baidu.com/api/trans/vip/translate`，一般不用改 |
| | 目标语言 | 简体中文 / English |
| | 翻译内容 | 仅歌曲名 / 仅歌手 / 两者 |
| | 测试翻译 | 用示例文本验证密钥、网络、签名 |
| 命名 | 文件名格式 | 歌曲名 - 歌手 / 歌手 - 歌曲名 / 仅歌曲名 |
| | 非法字符 | 替换为空格 / 下划线 / 直接删除 |
| 识别 | 重音拉丁视为英文 | 开启时 `Café`、`Björk` 不触发翻译 |
| 容错 | 翻译失败时 | 保留原文继续 / 跳过该文件 |
| | 缓存翻译结果 | 相同文本只请求一次，降低额度消耗 |
| | 超时 / 失败重试 | 2~60 秒、0~5 次 |

## 翻译规则

- 只检查**字母文字**：汉字视为中文，ASCII 及（默认）带重音的拉丁字母视为英文；
- 出现假名、谚文、西里尔、希腊、泰文、阿拉伯文等文字时，才调用翻译；
- 数字、标点、emoji、符号不会触发翻译；
- 日文歌名里只有汉字（如「夜曲」）时按中文处理，不翻译；
- 翻译只影响输出文件名，**不改 ID3 标签**；
- 失败时按设置保留原名继续，或跳过该文件，日志会写明原因与错误码。

## 百度翻译 API 说明

1. 打开 <https://fanyi-api.baidu.com/> 注册并登录；
2. 开通「通用文本翻译」服务，在管理控制台拿到 **APP ID** 和**密钥**；
3. 把两项填进设置页，点「测试翻译」。

使用的是百度翻译开放平台 **通用翻译 API**：`sign = md5(APP ID + q + salt + 密钥)`，
`from=auto` 自动识别源语言。标准版免费额度为每月 5 万字符（以百度官网为准）；
开启缓存可显著减少重复请求。

密钥以明文保存在 `settings.json` 中，**不要把这个文件分享给别人**。

## 命令行参数

```
python volume_tool.py <输入> [--db N | --percent N] [--rename] [选项]
```

| 参数 | 说明 |
| --- | --- |
| `输入` | mp3 文件或文件夹 |
| `-v, --db N` | 降低 N 分贝，常用 3~12 |
| `-p, --percent N` | 把音量降到原来的 N%（50 = 降一半） |
| `--rename` | 输出文件按 ID3 标签命名；不加则只降音量 |
| `--translate` | 本次启用百度翻译（覆盖设置里的开关） |
| `--settings FILE` | 使用指定设置文件 |
| `-o, --out DIR` | 输出文件夹，默认「输入位置\output」 |
| `--in-place` | 原地覆盖原文件（不能与 `--rename` 同用） |
| `-j, --jobs N` | 同时处理几个文件，默认 4 |
| `--bitrate` | `auto`（默认 VBR 约 190 kbps）或固定码率如 `320k` |
| `--overwrite` | 输出文件已存在时覆盖，默认跳过 |
| `--no-recursive` | 只处理文件夹第一层 |
| `--dry-run` | 只看会生成什么名字，不写文件 |
| `--gui` | 打开图形界面 |

示例：

```
# 整个歌单降低 6 dB
python volume_tool.py "D:\Music" -v 6

# 复制到输出目录并按标签改名（不改音量、不改原文件）
python volume_tool.py "D:\Music" --rename

# 降音量 + 按标签命名 + 外文自动翻译
python volume_tool.py "D:\Music" -v 3 --rename --translate

# 先预览新文件名（会用到翻译）
python volume_tool.py "D:\Music" --rename --dry-run
```

## 音量数值怎么选

| 数值 | 听感 |
| --- | --- |
| 3 dB | 轻微变小，约原来的 71% |
| 6 dB | 明显变小，约原来的一半 |
| 10 dB | 小很多，约原来的 32% |
| 20 dB | 当背景音，约原来的 10% |

换算：`dB = 20 × log10(100 / 百分比)`。

## 输出规则

- 默认输出到 `<输入位置>\output`，保留子文件夹结构；输入目录下的 `output` 会自动跳过；
- 目标文件已存在时默认跳过，加 `--overwrite` 覆盖；
- `--in-place` 先写临时文件，成功后才替换原文件；
- 只重命名模式是直接复制，不重新编码，音质不变；
- ID3 标签与封面会保留。

## 代码结构（维护用）

```
volume_tool.py            入口，只负责调用 mp3tools.cli.main（保持原文件名，bat 不受影响）
mp3tools/
├── __main__.py           python -m mp3tools 的入口
├── config.py             设置模型、默认值、settings.json 读写、选项常量
├── errors.py             ToolError
├── media.py              ffmpeg/ffprobe 定位、媒体探测、音量滤镜与编码参数
├── translate.py          字符检测、百度翻译签名/请求、翻译缓存
├── naming.py             文件名清理与拼接（调用翻译）
├── batch.py              文件收集、任务规划、编码/复制、并发与汇总
├── cli.py                参数解析与终端输出
├── gui.py                主窗口
└── settings_ui.py        设置页
```

依赖方向是单向的，改一个模块不容易牵连其它模块：

```
config / errors  →  media / translate  →  naming  →  batch  →  cli / gui / settings_ui
```

常见改动位置：

| 想改什么 | 去哪里 |
| --- | --- |
| 主窗口文字、布局、新按钮 | `gui.py` |
| 设置页选项、测试翻译按钮 | `settings_ui.py` |
| 新增设置项 | `config.py`（字段、默认值、校验）+ `settings_ui.py` |
| 翻译规则、错误码、请求参数 | `translate.py` |
| 文件名格式、非法字符处理 | `naming.py`（选项常量在 `config.py`） |
| 音量算法、编码参数 | `media.py`、`batch.py` |
| 命令行参数与输出格式 | `cli.py` |

两种启动方式等价：

```
python volume_tool.py        # 入口脚本
python -m mp3tools           # 包入口
```

命令行模式不会加载 tkinter（`cli.py` 里是延迟导入 `gui`），无图形环境也能用。

## 依赖

- Python 3.9+（在 3.15 上测试）
- **ffmpeg**（含 ffprobe）：PATH 中可用即可。程序会依次查找
  `FFMPEG_BIN` 环境变量 → PATH（含注册表最新 PATH）→ 脚本旁 `bin\ffmpeg.exe` → 常见安装位置
- tkinter（Windows 官方 Python 自带，仅界面需要）

## 常见问题

**歌名没翻译？**
确认：已启用翻译、填了密钥、`翻译内容`包含歌曲名；并且文字确实含日文/韩文等字符
（纯中文、纯英文、只有汉字的日文名不会翻译）。

**提示“未授权用户 / 签名错误”？**
对应百度错误码 52003 / 54001：检查 APP ID 与密钥是否复制完整、是否已开通「通用文本翻译」
且应用已生效；用设置页的「测试翻译」定位。错误码 54003 表示请求过于频繁，稍后再试；
开缓存可减少请求。

**提示“HTTPS 证书校验失败”？**
这是本机 Python 缺少根证书（macOS 的 python.org 版常见），与百度接口无关：
运行 Python 安装目录里的 `Install Certificates.command`（如
`/Applications/Python 3.11/Install Certificates.command`），然后重新打开程序。

**翻译失败会怎样？**
默认保留原文继续命名，日志里会记录失败原因；可在设置里改成「跳过该文件」。

**密钥安全吗？**
密钥明文存在 `settings.json`，仅本机可见；不要分享该文件，也不要提交到代码仓库。

**只重命名会重新编码吗？**
不会，直接复制文件，音质、大小、标签完全不变。

**降低值准不准？**
实测误差 ±0.05 dB 以内（`astats` 校验）。固定 192k 编码有约 0.27 dB 偏差，故默认用 VBR。

**处理到一半关掉会怎样？**
临时文件会被丢弃；原文件不受影响。
